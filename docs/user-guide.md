# 使用指南

本文说明面板界面、各功能含义，以及日常怎么操作。手把手流程见 **[分步教程](tutorials.md)**。

---

## 面板是做什么的？

Mystery Dashboard 运行在你**本机**上：用网页管理多个 Minecraft **服务端**（不是启动游戏客户端）。你可以下载/导入服务端、启动 Java 进程、看日志、改配置、管文件——相当于轻量版 MCSManager。

每个实例唯一托管在 `DATA_DIR/instances/<id>`。`DATA_DIR` 可为相对项目根目录的路径或绝对路径，但实例始终位于其 `instances/<id>` 下。面板不支持自定义实例目录，不提供全盘目录浏览；所有实例进程固定使用 PATH 中的 `java`。

**访问地址**

| 模式 | 地址 |
|------|------|
| 开发（Vite） | `http://127.0.0.1:5173` |
| 生产（`npm start`） | `http://127.0.0.1:3000` |

默认只监听本机，外网无法直接访问（见 [配置说明](configuration.md)）。

登录后左侧为 **侧栏**，右侧为 **主内容区**。

```
┌─────────────────┬──────────────────────────────────┐
│ Mystery Dashboard│  页面标题 + 说明                    │
│ Minecraft 服务端 │  ─────────────────────────────    │
│                  │  主内容（表格 / 表单 / 控制台）      │
│ [实例总览]       │                                  │
│ [一键部署]       │                                  │
│ [导入安装包]     │                                  │
│                  │                                  │
│ 用户名           │                                  │

```

| 侧栏入口 | 路由 | 作用 |
|----------|------|------|
| 实例总览 | `/` | 所有实例列表与快捷启停 |

实例详情路由：`/instances/<实例ID>`，顶部有 **控制台 / 文件 / 配置 / 设置** 四个 Tab。

## 登录与账号

### 首次使用（初始化管理员）

1. 按 [快速开始](getting-started.md) 配置 `JWT_SECRET` 和 `SETUP_TOKEN`。
2. 打开面板，执行初始化请求时在 `X-Setup-Token` header 中携带 `SETUP_TOKEN`。
3. 输入用户名和至少 12 位密码，创建管理员。
4. 创建成功后，从 `.env` 移除 `SETUP_TOKEN` 并重启面板；以后使用普通登录。

setup 仅在用户表为空时可用。当前版本只能有一个管理员，初始化后不能再注册第二个账号。

### 日常登录

- 标题 **「登录面板」** → 输入账号密码 → **「登录」**。
- 登录信息保存在浏览器 `localStorage`（键 `mmd_token`）。清除站点数据后需重新登录。

### 安全建议

- 使用强密码；面板能读写实例文件并启动进程，等同于高权限工具。
- 不要在公共电脑上保持登录状态。
- 不要把 `JWT_SECRET` 或 `SETUP_TOKEN` 发给其他人或提交到仓库。

## 实例总览

**作用**：一眼看到所有服的状态，并做批量操作。

| 列 / 区域 | 说明 |
|-----------|------|
| 名称 | 点击进入该实例详情 |
| 核心 | `paper`、`fabric`、`vanilla`、`forge`、`neoforge`、`custom` 等 |
| 版本 | Minecraft 版本号（自定义导入可能为 `-`） |
| 状态 | 彩色徽章，见下表 |
| 操作 | 启动、停止、重启、删除、接管（适用于旧版记录） |

页面每约 **3 秒** 自动刷新状态。右上角还有 **一键部署**、**导入安装包** 快捷按钮。

### 实例状态

| 界面显示 | 含义 | 你可做的 |
|----------|------|----------|
| 已停止 | 没有运行中的 Java 进程 | 可启动 |
| 启动中 | 正在拉起进程 | 等待 |
| 运行中 | 服务端已启动 | 可进游戏、发控制台命令 |
| 停止中 | 正在结束进程 | 等待 |
| 已崩溃 | 进程异常退出 | 看控制台日志排错 |

**按钮逻辑**

- **启动**：仅在非「运行中」时可用。
- **停止**：仅在非「已停止」时可用。
- **重启**：任意时刻可点（会先停再启）。
- **接管**：仅用于已复制到面板托管目录的旧版实例，实例和面板服务应先停止。
- **删除**：需确认；删除数据库记录和面板托管的实例目录，且须先停止实例。旧版外部目录不会被访问或删除。

## 一键部署（表单说明）

从 Mojang / Paper / Fabric / Forge / NeoForge 官方（或镜像）拉取文件并创建实例。

| 字段 | 说明 |
|------|------|
| 实例名称 | 在总览中显示的名字 |
| 核心类型 | Paper / Fabric / Forge / NeoForge / Vanilla |
| 游戏版本 | 滚动下拉，远程加载版本列表 |
| Paper Build | 仅 Paper；`#数字`，默认一般为最新 |
| Loader / Forge / NeoForge 版本 | 模组加载器版本；Fabric 另有 Installer 版本 |
| JVM 参数 | 空格分隔，如 `-Xms1G -Xmx2G` |
| 自动接受 EULA | 启动/部署时写入 `eula=true` |

部署目标由面板自动分配为 `DATA_DIR/instances/<id>`，表单不能更改。Java 也不在表单中指定；部署和运行都使用 PATH 中的 `java`。可通过系统 Java 状态接口确认 `java` 是否可用。

点击 **「开始部署」** 后出现 **进度条与文字说明**（下载、解压、安装等）。任务可能先显示为 **排队**；前端会持续显示并刷新任务状态，直到完成或失败，完成后 **自动跳转** 到新实例控制台。

达到任务并发上限时任务会排队，等待队列已满则请求返回 **429**。任务开始执行后超过 `TASK_TIMEOUT_MS` 会失败；排队期间不要重复提交同一任务。

**Forge / NeoForge 提示**：会下载 Installer 并执行 `--installServer`，时间可能较长，请勿关闭浏览器或停掉后端。

## 导入安装包（表单说明）

| 字段 | 说明 |
|------|------|
| 实例名称 | 同部署 |
| 安装包（`.zip`） | 必选；最大约 512 MiB，受上传和 ZIP 配额共同限制；超出上传大小返回 413，上传容量满返回 429 |
| JVM 参数 | 可选；为空时使用默认值 |
| 自动接受 EULA | 可选 |

导入流程：解压到新建的 `DATA_DIR/instances/<id>` → 若只有一层根文件夹则自动展平 → **自动探测** 服务端 jar → 写入实例设置。若探测失败，任务会报错「未找到可用的 .jar」。导入同样固定使用 PATH 中的 `java`。上传文件超限返回 413；上传处理槽位已满返回 429。

## 实例目录与 Java 状态

### 实例目录

- 面板只在 `DATA_DIR/instances/<id>` 内创建、读取和修改实例文件。
- 「文件」页显示的是当前实例根目录下的逻辑路径，不是本机全盘文件夹选择器。
- 不能把实例设置到其他位置，也不能通过文件 API 访问实例根目录以外的路径。

### Java 状态

面板不安装 Java、不接受完整 Java 路径，也不提供 Java 选择器。运行面板的同一环境中执行：

```bash
java -version
```

系统状态接口 `GET /api/system/java` 返回：

```json
{ "available": true, "version": "21.0.3" }
```

不可用时返回 `{ "available": false, "version": null }`。探测命令和实例进程使用的是同一个 PATH `java`。

## 实例详情

顶部显示实例名、核心、版本、状态，以及 **启动 / 停止 / 重启**。链接 **「← 返回总览」** 回到列表。

### 控制台

- 黑色终端区域（xterm.js），实时显示服务端 stdout/stderr。
- **输入命令 + 回车** 发送到服务端（与游戏内控制台一致）。
- 连接断开或刷新页面后会重连，并先加载历史日志；缓冲受 `MAX_CONSOLE_BUFFER_BYTES` 和 `MAX_CONSOLE_CHUNK_BYTES` 限制。
- 控制台最多同时 `20` 个连接；单条命令最多 `4096` 字节，每 `60000` 毫秒最多发送 `60` 条命令。单个入站消息最多 `4352` 字节，写入服务端 stdin 的待处理输入最多 `65536` 字节；超出连接、命令、速率或输入缓冲限制时不会继续写入。
- 若显示未授权，尝试 **退出登录再登录**（WebSocket 使用短期一次性 console ticket）。

### 文件

左右两栏均限定在当前实例根目录：

| 左侧 | 右侧 |
|------|------|
| 当前逻辑路径、文件列表 | 文本编辑区 |
| **上级** 返回实例内父目录 | 点击左侧 **📄 文本文件** 后显示内容 |
| **上传** 到当前实例目录 | **保存** 写回磁盘 |
| 每项 **删除** | 大文件 / 二进制不适合在线编辑 |
| **新建文件夹** | |

路径显示为 `/` 开头的逻辑路径（相对实例根目录）。修改 `mods`、`plugins`、世界数据前建议 **先停服**。

文件下载默认最多 4 个并发；并发容量已满时请求返回 **429**。下载空闲超时会关闭连接并释放下载资源，相关配置见 [配置说明](configuration.md)。

### 配置

- 以表单展示 `server.properties` 全部键值。
- **保存配置** 后需 **重启实例** 才能生效（页面有说明）。
- 与直接编辑 `server.properties` 文件等价。

### 设置

| 字段 | 说明 |
|------|------|
| 名称 | 可改 |
| Jar 文件名 | 相对实例目录，如 `server.jar` |
| JVM 参数 | 可改；改后建议重启 |
| 启动时自动写入 eula=true | 勾选后每次启动会写 `eula.txt` |
| 实例目录 | 只读显示为 `DATA_DIR/instances/<id>` |
| Java | 只读显示为固定命令 `java` |

**保存设置** 后弹出「设置已保存」。

## Java 与 Minecraft 版本（实用参考）

面板不自动安装 Java，需本机 PATH 中已有 JDK。版本不匹配时控制台常见 `UnsupportedClassVersionError` 或无法启动。

| Minecraft 版本（大致） | 建议 Java |
|------------------------|-----------|
| 1.20.5 及更新 | Java **21** |
| 1.18 – 1.20.4 | Java **17** |
| 1.17 | Java **16** |
| 1.16 及更旧 | Java **8** 或 **11**（视具体核心文档） |

以你所选 **Paper / Forge 官方说明** 为准；启动前用 `java -version` 确认 PATH 中的版本。

## 停止与强杀

界面上只有 **「停止」**（正常结束进程）。若进程卡死，目前需通过 API `POST /api/instances/:id/stop?force=1` 强杀（面向开发者，见 [API](api.md)）。日常使用可先试 **重启**。

## 数据存在哪里？

| 内容 | 默认位置 |
|------|----------|
| 实例元数据 | `DATA_DIR/panel.db` |
| 实例文件 | `DATA_DIR/instances/<id>/` |
| 核心下载缓存 | `DATA_DIR/cache/cores/` |
| 上传临时文件 | `DATA_DIR/uploads/` |

删除实例会删掉对应的面板托管目录全部内容。旧版外部目录不由面板访问或删除。

默认 `DATA_DIR` 为项目根目录下的 `data`；也可以在 `.env` 中填写绝对路径。无论配置方式如何，实例唯一目录都是 `DATA_DIR/instances/<id>`。

## 旧版外部实例接管

旧版外部实例是数据库中仍记录旧目录、但尚未迁入面板托管根目录的实例。面板不会访问旧目录，也不会自动搬迁或删除它。

1. 停止该实例，并停止面板服务。
2. 用操作系统的复制工具，将旧外部目录完整复制到 `DATA_DIR/instances/<id>`。
3. 启动面板，进入对应实例，点击 **接管**。
4. 接管成功后，实例才按面板托管目录处理；旧目录仍由用户自行保留或管理。

若目标目录为空、不完整、ID 不对应或实例仍在运行，接管会失败。请不要在面板中尝试通过文件页访问旧目录。

## 常见问题

### 部署或导入一直卡住

- 检查本机能否访问外网（Mojang、Paper、Fabric、Forge 镜像等）。
- 看进度条 **message** 停在哪一步；Forge/NeoForge 安装尤其慢。
- 后端终端日志可能有更详细错误。
- 检查任务并发、排队和超时配置是否被调得过小。
- 页面显示「排队」时属于正常状态；前端会继续刷新任务状态，直到任务完成或失败。只有等待队列已满才会返回 429。

### 启动后立即「已崩溃」

1. 打开 **控制台** 看最后几行错误。
2. **设置** 检查 Jar 文件名和 JVM 参数。
3. 在运行面板的同一环境中执行 `java -version`，确认 PATH 命令可用且版本匹配。
4. 若提示 EULA，勾选 **自动写入 eula=true** 或手动在文件中写 `eula=true`。

### 游戏连不上服务器

- 服务端是否 **运行中** 且控制台已 `Done`。
- `server.properties` 里 **server-port** 是否与游戏填的端口一致。
- 本机测试用 `127.0.0.1`；局域网用主机局域网 IP。
- 防火墙是否放行 Java 或该端口。

### 401 / 未授权

- 重新 **登录**。
- 开发模式确认 **后端 3000** 与 **前端 5173** 都在运行。
- setup 失败时确认 header 名为 `X-Setup-Token`，且用户表为空。

### 导入 zip 失败

- 确认是 **zip** 且小于 512 MiB，并符合 ZIP 配额。
- 若响应为 **413**，表示上传文件超过大小上限；若为 **429**，表示上传处理容量暂时已满，请等待后重试。
- 包内是否包含服务端 jar（不是仅客户端）。
- zip 是否带恶意路径（面板会拒绝 zip-slip）。

### 忘记管理员密码

当前无「忘记密码」功能。需停服后自行处理 `DATA_DIR/panel.db` 中 `users` 表，或删除 `panel.db` 重新初始化（会丢失实例注册信息，磁盘上的实例文件仍在）。重新初始化时必须重新配置 `SETUP_TOKEN`。

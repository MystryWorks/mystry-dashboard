# 使用指南

本文说明面板界面、各功能含义，以及日常怎么操作。手把手流程见 **[分步教程](tutorials.md)**。

---

## 面板是做什么的？

Mystery Dashboard 运行在你**本机**上：用网页管理多个 Minecraft **服务端**（不是启动游戏客户端）。你可以下载/导入服务端、启动 Java 进程、看日志、改配置、管文件。

每个实例唯一托管在 `DATA_DIR/instances/<id>`。`DATA_DIR` 可为相对项目根目录的路径或绝对路径，但实例始终位于其 `instances/<id>` 下。面板不支持自定义实例目录，不提供全盘目录浏览；实例默认使用 PATH 中的 `java`，也可绑定面板扫描并验证的运行时。

**访问地址**

| 模式 | 地址 |
|------|------|
| 开发（Vite） | `http://127.0.0.1:5173` |
| 生产（`npm start`） | `http://127.0.0.1:3000` |

默认只监听本机，外网无法直接访问（见 [配置说明](configuration.md)）。

## 登录与账号

### 首次使用（初始化管理员）

1. 按 [快速开始](getting-started.md) 配置 `JWT_SECRET` 和 `SETUP_TOKEN`。
2. 打开面板，执行初始化请求时在 `X-Setup-Token` header 中携带 `SETUP_TOKEN`。
3. 输入用户名和至少 12 位密码，创建管理员。
4. 创建成功后，从 `.env` 移除 `SETUP_TOKEN` 并重启面板；以后使用普通登录。

setup 仅在用户表为空时可用。当前版本只能有一个管理员，初始化后不能再注册第二个账号。

### 日常登录

- 标题 **「登录面板」** → 输入账号密码 → **「登录」**。
- 登录信息保存在浏览器 `localStorage`（键 `mmd_token`）。清除站点数据后需重新登录。

### 安全建议

- 使用强密码；面板能读写实例文件并启动进程，等同于高权限工具。
- 不要在公共电脑上保持登录状态。
- 不要把 `JWT_SECRET` 或 `SETUP_TOKEN` 发给其他人或提交到仓库。

## 实例总览

**作用**：一眼看到所有服的状态，并做批量操作。

| 列 / 区域 | 说明 |
|-----------|------|
| 名称 | 点击进入该实例详情 |
| 核心 | `paper`、`fabric`、`vanilla`、`forge`、`neoforge`、`custom` 等 |
| 版本 | Minecraft 版本号（自定义导入可能为 `-`） |
| 状态 | 彩色徽章，见下表 |
| 操作 | 查看实例及当前可执行的启动/停止；重启、强制停止、删除收在「更多操作」中 |

页面每约 **3 秒** 自动刷新状态。右上角保留横向排列的 **一键部署**、**导入已有服务端** 主入口；上传自定义 `server.jar` 时使用下方的 **创建空实例** 次级入口。首次加载会明确显示读取状态，刷新失败时保留上次成功数据并提示可能已过期。

### 实例状态

| 界面显示 | 含义 | 你可做的 |
|----------|------|----------|
| 已停止 | 没有运行中的 Java 进程 | 可启动 |
| 启动中 | 正在拉起进程 | 等待 |
| 运行中 | 服务端已启动 | 可进游戏、发控制台命令 |
| 停止中 | 正在结束进程 | 等待 |
| 已崩溃 | 进程异常退出 | 看控制台日志排错 |

**按钮逻辑**

- **启动**：仅在非「运行中」时可用。
- **停止**：仅在非「已停止」时可用。
- **重启**：任意时刻可点（会先停再启），确认弹窗会提示中断风险。
- **接管**：仅用于已复制到面板托管目录的旧版实例，实例和面板服务应先停止。
- **删除**：需确认；托管实例还必须输入实例名称，才会删除数据库记录和实例目录，且须先停止实例。旧版外部目录不会被访问或删除。

## 一键部署（表单说明）

从 Mojang / Paper / Fabric / Forge / NeoForge 官方（或镜像）拉取文件并创建实例。

| 字段 | 说明 |
|------|------|
| 实例名称 | 在总览中显示的名字 |
| 核心类型 | Paper / Fabric / Forge / NeoForge / Vanilla |
| 游戏版本 | 滚动下拉，远程加载版本列表 |
| Paper Build | 仅 Paper；`#数字`，默认一般为最新 |
| Loader / Forge / NeoForge 版本 | 模组加载器版本；Fabric 另有 Installer 版本 |
| JVM 设置 | 选择最大内存与优化方案；高级区可设置 Xms 和附加参数 |
| 自动接受 EULA | 启动/部署时写入 `eula=true` |

部署目标由面板自动分配为 `DATA_DIR/instances/<id>`，表单不能更改。部署表单可选择 Java 运行时：默认是 PATH 中的 `java`，也可点「重新探测」后选择面板扫描并验证的条目；不能手填路径。选择的运行时会用于 Forge / NeoForge Installer 和实例启动。

点击 **「开始部署」** 后出现 **进度条与文字说明**（下载、解压、安装等）。任务可能先显示为 **排队**；前端会持续显示并刷新任务状态，直到完成或失败，完成后 **自动跳转** 到新实例控制台。

达到任务并发上限时任务会排队，等待队列已满则请求返回 **429**。任务开始执行后超过 `TASK_TIMEOUT_MS` 会失败；排队期间不要重复提交同一任务。

**Forge / NeoForge 提示**：会下载 Installer 并执行 `--installServer`，时间可能较长，请勿关闭浏览器或停掉后端。

### JVM 配置器

一键部署、导入、创建空实例和实例设置使用同一个配置器。基础界面只需要选择最大内存和优化方案，最终参数会在下方按标签预览；高级区域可改为手动 `Xms` 并填写附加参数。

- **兼容优先**：只生成内存参数，`Xms` 自动取 `min(1 GiB, Xmx)`。
- **G1 均衡**：在兼容内存基础上启用 G1、并行引用处理和 200 ms 暂停目标，仅在已识别 Java 8 / 17 / 21 时可选。
- **Paper Aikar**：仅 Paper 与已识别 Java 8 / 17 / 21 可选，自动令 `Xms=Xmx`；低于 6 GiB 会提示警告。界面同时显示冻结版本、复核日期和 PaperMC 官方来源。

推荐最大内存约为本机总内存的 25%，按 512 MiB 向下取整，通常不低于 2 GiB、不高于 8 GiB，并为系统预留至少 2 GiB；低内存机器可降到 1 GiB，节点内存不可读时回退 2 GiB。资源偏高、Java 版本未验证和 Paper 内存不足是警告；未闭合引号、内存重复或顺序错误、GC 冲突，以及 `-jar`、classpath、模块启动、`@argfile`、`nogui` 等面板负责的启动参数会阻止保存。

## 导入已有服务端（表单说明）

页面提供两种方式，都会创建新的 `DATA_DIR/instances/<id>` 托管副本，不会让实例直接在原目录运行。

### 同机目录交接

适用于服务端已经部署在面板所在机器，但当前不由面板管理的情况：

1. 在原控制台正常停止服务器，确认世界保存完成。
2. 把完整服务端目录复制到 `DATA_DIR/imports/<目录名>`。不要只复制 jar；世界、插件、模组和配置都应一并复制。
3. 打开 **导入已有服务端 → 同机目录交接**，点 **刷新目录**，选择候选目录。
4. 若根目录检测到 `user_jvm_args.txt`，明确选择 **沿用检测参数 / 使用面板推荐 / 自定义配置**；解析失败时不能沿用。
5. 核对实例名称、核心类型、Minecraft 版本、JVM 设置和 Java 运行时，点 **复制并接管**。
6. 等待任务完成并跳转到实例页，先检查文件和配置，再从面板启动。

面板只会列出 `DATA_DIR/imports` 的直接子目录，API 不接受系统绝对路径，也不提供全盘浏览。复制时会拒绝 symlink/junction、特殊文件、面板实例标记以及超过配额的目录；还会确认目标磁盘空间。原目录和交接区副本都不会被面板删除。确认托管实例运行正常后，可由管理员自行清理交接区副本。

> 不要在原服务器仍运行时复制。面板无法锁定外部进程，运行中复制可能得到不一致的世界数据。

### 上传 ZIP

| 字段 | 说明 |
|------|------|
| 安装包（`.zip`） | 必选；最大约 512 MiB，受上传和 ZIP 配额共同限制；超出上传大小返回 413，上传容量满返回 429 |
| 实例名称 | 预检成功后填写，同部署 |
| 核心类型 / Minecraft 版本 | 可选；用于实例展示和 Java 版本提示，启动文件仍由面板探测 |
| JVM 设置 | 预检成功后使用统一配置器；检测到参数时必须明确选择处理方式 |
| Java 运行时 | 默认使用 PATH，也可选择面板已探测并验证的运行时 |
| 自动接受 EULA | 可选 |

导入分两步：先点 **上传并预检**，服务端验证 ZIP 中央目录并只读取根目录或单一顶层目录中的普通 `user_jvm_args.txt`（最大 64 KiB）；再确认实例、Java 和 JVM 设置，点 **确认配置并导入** 后才创建后台任务。刷新或离开页面后，同一登录用户会从 `sessionStorage` 恢复待确认预览；也可取消并立即删除临时 ZIP。预览默认 30 分钟有效，过期或面板重启后需要重新上传。

后台任务会解压到新建的 `DATA_DIR/instances/<id>` → 若只有一层根文件夹则自动展平 → **自动探测** 普通服务端 jar 或现代 Forge / NeoForge args 启动文件 → 写入实例设置。若任务队列已满，确认返回 429，但预览会保留以便重试。上传文件超限返回 413；上传处理或预览容量已满返回 429。

## 实例目录与 Java 状态

### 实例目录

- 面板只在 `DATA_DIR/instances/<id>` 内创建、读取和修改实例文件。
- `DATA_DIR/imports/<目录名>` 仅是同机交接源；导入完成后的实例仍只在 `instances/<id>` 运行。
- 「文件」页显示的是当前实例根目录下的逻辑路径，不是本机全盘文件夹选择器。
- 不能把实例设置到其他位置，也不能通过文件 API 访问实例根目录以外的路径。

### Java 状态

面板不安装 Java，也不接受手填完整路径。运行面板的同一环境中执行：

```bash
java -version
```

系统状态接口 `GET /api/system/java` 返回：

```json
{ "available": true, "version": "21.0.3", "majorVersion": 21 }
```

不可用时返回 `{ "available": false, "version": null }`。这是**默认 PATH 运行时**的状态。

需要使用其他已安装 Java 时，在「一键部署」或实例「设置」中的 **Java 运行时**点击「重新探测」。候选只来自 `JAVA_HOME` 和常见安装目录，并会执行 `-version` 验证；选择器中的「不可用」条目表示最近一次扫描未再发现它，需重新选择。已绑定运行时会在实例启动和 Forge / NeoForge Installer 执行前再次验证。

## 实例详情

顶部显示实例名、核心、版本、状态，以及 **启动 / 停止 / 重启**。链接 **「← 返回总览」** 回到列表。

### 控制台

- 黑色终端区域（xterm.js），实时显示服务端 stdout/stderr。
- **输入命令 + 回车** 发送到服务端（与游戏内控制台一致）。
- 连接断开或刷新页面后会重连，并先加载历史日志；缓冲受 `MAX_CONSOLE_BUFFER_BYTES` 和 `MAX_CONSOLE_CHUNK_BYTES` 限制。
- 控制台最多同时 `20` 个连接；单条命令最多 `4096` 字节，每 `60000` 毫秒最多发送 `60` 条命令。单个入站消息最多 `4352` 字节，写入服务端 stdin 的待处理输入最多 `65536` 字节；超出连接、命令、速率或输入缓冲限制时不会继续写入。
- 若显示未授权，尝试 **退出登录再登录**（WebSocket 使用短期一次性 console ticket）。

### 文件

左右两栏均限定在当前实例根目录：

| 左侧 | 右侧 |
|------|------|
| 当前逻辑路径、文件列表 | 文本编辑区 |
| **上级** 返回实例内父目录 | 点击左侧文本文件后的 **编辑** 打开内容 |
| **上传** 到当前实例目录 | **保存** 写回磁盘 |
| 每项 **下载**（仅普通文件）、**重命名**、**删除** | 大文件 / 二进制不适合在线编辑 |
| **新建文件夹** | |

文件页提供 **下载**（一次性 ticket + 浏览器原生下载，不整包缓冲）与同目录 **重命名**。下载并发已满时会提示「下载繁忙，请稍后重试」。需要整目录拷贝时仍可停服后用系统工具操作实例目录。

文件列表会区分首次读取、刷新、空目录和失败状态。删除文件或文件夹统一使用确认弹窗；删除文件夹会递归删除其内容，弹窗会显示逻辑路径并明确提示不可恢复。

路径显示为 `/` 开头的逻辑路径（相对实例根目录）。修改 `mods`、`plugins`、世界数据前建议 **先停服**。

文件下载 API 默认最多 4 个并发；并发容量已满时请求返回 **429**。下载空闲超时会关闭连接并释放下载资源，相关配置见 [配置说明](configuration.md)。

### 配置

- 常用 `server.properties` 键按基础、多人和权限、世界、性能分组展示；未收录的键保留在「高级选项」中。
- **保存配置** 后需 **重启实例** 才能生效（页面有说明）。
- 页面会标记未保存修改；无变化时保存按钮不可用。保存成功后持续提示需要重启；切换页面时先显示放弃修改确认，关闭或刷新浏览器标签页前也会触发未保存警告。
- 与直接编辑 `server.properties` 文件等价。

### 设置

| 字段 | 说明 |
|------|------|
| 名称 | 可改 |
| Jar 文件名 | 相对实例目录，如 `server.jar` |
| JVM 设置 | 使用统一配置器修改内存、预设和高级参数；改后建议重启 |
| 启动时自动写入 eula=true | 勾选后每次启动会写 `eula.txt` |
| 实例目录 | 只读显示为 `DATA_DIR/instances/<id>` |
| Java 运行时 | 默认 PATH `java`，或选择面板探测并验证的运行时；可重新探测 |

设置页会标记未保存修改，保存期间锁定表单并在页面内显示成功或失败结果；切换页面前会确认是否放弃修改，不再使用浏览器原生提示框。

**保存设置** 后会在设置页内显示「设置已保存」。

## Java 与 Minecraft 版本（实用参考）

面板不自动安装 Java，需本机安装适配的 JDK。可将常用版本配置到 PATH 作为默认，或在面板中探测并绑定其他安装版本。版本不匹配时控制台常见 `UnsupportedClassVersionError` 或无法启动。

| Minecraft 版本（大致） | 建议 Java |
|------------------------|-----------|
| 1.20.5 及更新 | Java **21** |
| 1.17 – 1.20.4 | Java **17** |
| 1.16 及更旧 | Java **8** 或 **11**（视具体核心文档） |

以你所选 **Paper / Forge 官方说明** 为准；默认运行时用 `java -version` 检查，已绑定实例则查看设置页中所选运行时的版本和可用状态。

## 停止与强杀

界面提供普通 **「停止」** 与 **「强制停止」**（实例详情与总览「更多操作」中均可用；强制停止需确认弹窗）。强制停止对应 `POST /api/instances/:id/stop?force=1`，会立即强制结束进程，可能导致世界损坏，建议先试普通停止。日常卡死也可先试 **重启**。

## 数据存在哪里？

| 内容 | 默认位置 |
|------|----------|
| 实例元数据 | `DATA_DIR/panel.db` |
| 实例文件 | `DATA_DIR/instances/<id>/` |
| 核心下载缓存 | `DATA_DIR/cache/cores/` |
| 上传临时文件 | `DATA_DIR/uploads/` |

删除实例会删掉对应的面板托管目录全部内容。旧版外部目录不由面板访问或删除。

默认 `DATA_DIR` 为项目根目录下的 `data`；也可以在 `.env` 中填写绝对路径。无论配置方式如何，实例唯一目录都是 `DATA_DIR/instances/<id>`。

## 旧版外部实例接管

旧版外部实例是数据库中仍记录旧目录、但尚未迁入面板托管根目录的实例。面板不会访问旧目录，也不会自动搬迁或删除它。

1. 停止该实例，并停止面板服务。
2. 用操作系统的复制工具，将旧外部目录完整复制到 `DATA_DIR/instances/<id>`。
3. 启动面板，进入对应实例，点击 **接管**。
4. 接管成功后，实例才按面板托管目录处理；旧目录仍由用户自行保留或管理。

若目标目录为空、不完整、ID 不对应或实例仍在运行，接管会失败。请不要在面板中尝试通过文件页访问旧目录。

## 常见问题

### 部署或导入一直卡住

- 检查本机能否访问外网（Mojang、Paper、Fabric、Forge 镜像等）。
- 看进度条 **message** 停在哪一步；Forge/NeoForge 安装尤其慢。
- 后端终端日志可能有更详细错误。
- 检查任务并发、排队和超时配置是否被调得过小。
- 页面显示「排队」时属于正常状态；前端会继续刷新任务状态，直到任务完成或失败。只有等待队列已满才会返回 429。

### 启动后立即「已崩溃」

1. 打开 **控制台** 看最后几行错误。
2. **设置** 检查 Jar 文件名和 JVM 参数。
3. 默认运行时在面板同一环境中执行 `java -version` 检查；已绑定实例则确认「设置」中的运行时仍可用且版本匹配。
4. 若提示 EULA，勾选 **自动写入 eula=true** 或手动在文件中写 `eula=true`。

### 游戏连不上服务器

- 服务端是否 **运行中** 且控制台已 `Done`。
- `server.properties` 里 **server-port** 是否与游戏填的端口一致。
- 本机测试用 `127.0.0.1`；局域网用主机局域网 IP。
- 防火墙是否放行 Java 或该端口。

### 401 / 未授权

- 重新 **登录**。
- 开发模式确认 **后端 3000** 与 **前端 5173** 都在运行。
- setup 失败时确认 header 名为 `X-Setup-Token`，且用户表为空。

### 导入 zip 失败

- 确认是 **zip** 且小于 512 MiB，并符合 ZIP 配额。
- 若响应为 **413**，表示上传文件超过大小上限；若为 **429**，表示上传处理容量暂时已满，请等待后重试。
- 包内是否包含服务端 jar（不是仅客户端）。
- zip 是否带恶意路径（面板会拒绝 zip-slip）。

### 忘记管理员密码

当前无「忘记密码」功能。需停服后自行处理 `DATA_DIR/panel.db` 中 `users` 表，或删除 `panel.db` 重新初始化（会丢失实例注册信息，磁盘上的实例文件仍在）。重新初始化时必须重新配置 `SETUP_TOKEN`。

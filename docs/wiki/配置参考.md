# 配置参考

源码默认读仓库根 `.env`；便携 / PanelManager 默认读 `config/panel.env`。完整变量表见 [`.env.example`](../../.env.example) 与 [docs/configuration.md](../configuration.md)。

## 必填密钥

| 变量 | 何时需要 |
|------|----------|
| `JWT_SECRET` | 始终；JWT 签名 |
| `SETUP_TOKEN` | 用户表为空时；`X-Setup-Token` |
| `LAUNCHER_TOKEN` | 使用 PanelManager / `mmdctl` 安全停止时 |

三者必须是**互不相同**的 64 位十六进制随机值：

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

用户表为空且没有 `SETUP_TOKEN` 时面板不会启动。管理员创建后应移除 `SETUP_TOKEN` 并重启。

## 监听与 CORS

| 变量 | 默认 |
|------|------|
| `HOST` | `127.0.0.1` |
| `PORT` | `3000` |
| `CORS_ORIGINS` | `http://127.0.0.1:5173,http://localhost:5173` |

CORS 是精确白名单，**不要填 `*`**。

## 路径覆盖

| 变量 | 作用 |
|------|------|
| `MMD_HOME` | 运行布局根；须在启动 Node 前由进程环境设置 |
| `MMD_CONFIG_PATH` | 配置文件路径（源码默认 `.env`，便携默认 `config/panel.env`） |
| `MMD_DATA_DIR` | 优先于 `DATA_DIR`；实例仍只在其下 `instances/<id>` |

## 常用配额

| 项 | 默认 | 超限 |
|----|------|------|
| 上传 | `MAX_UPLOAD_BYTES=536870912`（512 MiB） | **413** |
| 上传 / 下载 / 任务并发满 | 上传 1、下载 4、任务见下 | **429** |
| 任务 | 1 running + 2 queued | 队列满 **429** |
| 控制台 | 20 连接；每 60s 最多 60 条命令 | 超限不写入 stdin |

## 管理器首次写入

`mmdctl` / PanelManager 首次启动会写 `config/panel.env`，生成三个随机 64-hex 密钥，并在空用户库时显示 setup token。管理员创建后，控制器会从配置中去掉 `SETUP_TOKEN`。不要提交或分享该文件。

## 升级

不要覆盖正在运行的目录：

1. 旧目录 `mmdctl stop`，`mmdctl status` 确认已停
2. 新版本解压到**新目录**
3. 把旧目录的 `config/`、`data/`、`logs/` 移到新目录
4. 新目录 `mmdctl start`，确认登录与存档后再归档旧应用目录

## Preview 限制

无安装器、无开机自启、Windows 产物未代码签名、不捆绑 Java、默认只监听回环。不要把面板端口直接暴露到不可信公网。

## 本地打包

```bash
npm run package:release
```

或指定平台：

```bash
node scripts/portable/package-portable.mjs --platform linux --arch x64
```

须在目标 OS / arch 原生执行。正式资产要求工作树干净。

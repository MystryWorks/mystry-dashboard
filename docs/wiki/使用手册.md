# 使用手册

日常怎么点。逐步流程见 [分步教程](分步教程.md)；字段级说明见 [docs/user-guide.md](../user-guide.md)。

## 侧栏

| 入口 | 路由 | 说明 |
|------|------|------|
| 实例总览 | `/` | 列表与快捷启停 |
| 一键部署 | `/deploy` | 从官方源安装核心 |
| 导入已有服务端 | `/import` | ZIP 或同机交接 |
| 节点管理 | `/nodes` | **只有本机** `local`；远程创建未开放 |
| 任务铃铛 | — | 部署 / 导入任务，离开页面后仍会刷新到终态 |
| 主题 | — | 亮 / 暗，保存在本浏览器 |

窄屏侧栏收成抽屉。任务中心桌面侧栏与移动顶栏共用同一份状态。

## 实例 Tab 与状态

实例页 `/instances/<id>`：**控制台 / 文件 / 配置 / 设置**。

| 状态 | 含义 |
|------|------|
| 已停止 | 无 Java 进程，可启动 |
| 启动中 | 正在拉起 |
| 运行中 | 可进游戏、发控制台命令 |
| 停止中 | 正在结束 |
| 已崩溃 | 异常退出，看控制台 |

总览约 **3 秒**刷新。主入口是 **一键部署** / **导入已有服务端**；次级入口是 **创建空实例**，再上传 jar。重启、强制停止、删除收在「更多操作」。

## 一键部署

核心：Vanilla / Paper / Fabric / Forge / NeoForge。目标固定为 `DATA_DIR/instances/<id>`，不能改路径。

任务可能先显示排队（pending）——前端会继续刷新，**不要重复提交**。Forge / NeoForge 会跑 Installer，耗时更长，保持面板进程与网络畅通。

## 导入

两种方式都会复制到新的 `DATA_DIR/instances/<id>`，不会在原目录运行。

**ZIP：** 先「上传并预检」根目录 `user_jvm_args.txt`，确认 JVM / Java 后再入队。超过约 512 MiB 返回 **413**；容量满返回 **429**。

**同机交接：** 只列出 `DATA_DIR/imports` 的**一层**子目录，API 不接受系统绝对路径。源目录**不会被删除**。复制前先在原控制台停服。

## 文件

路径相对实例根目录，不是全盘选择器。下载走一次性 ticket + 新标签页。同名冲突返回 **409**。文本文件不超过 **1 MiB** 可在线编辑。改 `mods` / `plugins` / 世界前先停服。

## 配置

`server.properties` 按基础、多人与权限、世界、性能分组；未收录键在「高级选项」。保存后**必须重启实例**才生效。

## JVM 与 Java

部署、导入、空实例、设置共用同一配置器：最大内存 + 兼容优先 / G1 / Paper Aikar，可填附加参数。Java **只能**从探测到的运行时 ID 选择（或不选，用 PATH `java`）。不能手填 Java 路径。

| Minecraft | 建议 Java |
|-----------|-----------|
| 1.20.5+ | 21 |
| 1.17–1.20.4 | 17 |
| 更旧 | 8 |

以所选核心官方说明为准。

## 危险操作

- **强制停止**：确认弹窗后请求 `POST /api/instances/:id/stop?force=1`，可能损坏世界。
- **不能删除运行中实例**，须先停止。
- **删除**须输入实例名称，会删掉托管目录全部文件。旧版外部目录面板不会访问或删除。

## 备份与旧目录

无自动备份。手动复制 `DATA_DIR/panel.db` 与 `DATA_DIR/instances/<id>/`。

旧版外部实例：停实例和面板后，用系统工具把完整目录复制进 `DATA_DIR/instances/<id>`，启动面板再点 **接管**。

更多场景：[docs/user-guide.md](../user-guide.md)、[docs/tutorials.md](../tutorials.md)。

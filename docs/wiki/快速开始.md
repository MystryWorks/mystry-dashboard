# 快速开始

把面板跑起来，并开出第一个可进游戏的服务端。逐步说明见 [docs/getting-started.md](../getting-started.md)。

## 环境要求

| 依赖 | 要求 |
|------|------|
| Node.js | **≥ 22**（源码运行；使用内置 `node:sqlite`） |
| Java | **自备**。面板不捆绑 Java，也不接受手填完整路径 |
| 源码管理器 | Windows（`PanelManager.cmd`）与 Linux / WSL（`PanelManager.sh`） |
| 便携包 | 仅 Windows x64 / Linux x64 |

## 便携包

解压后：

- Windows：双击 `mmdctl.cmd`，或 `.\mmdctl.cmd start`
- Linux：`chmod +x mmdctl && ./mmdctl start`

浏览器打开 <http://127.0.0.1:3000>。首次启动会在终端显示 setup token；不要分享或截图。

## 源码 PanelManager

Windows：双击仓库根目录 `PanelManager.cmd`，或 `PanelManager.cmd start`。

Linux / WSL：`chmod +x PanelManager.sh && ./PanelManager.sh start`。

默认访问 <http://127.0.0.1:3000>。

## 隔离测试数据

同一终端内，启动 / 停止 / 状态都要用同一组变量。

示例：

```bash
export MMD_CONFIG_PATH=/home/mocha/data/mystrydashboard-test/config/panel.env
export MMD_DATA_DIR=/home/mocha/data/mystrydashboard-test
```

然后执行 `./PanelManager.sh start`。

## 手动双终端开发

按下列命令安装依赖、构建 shared，并复制环境模板：

```bash
npm install
npm run build -w @mmd/shared
cp .env.example .env
```

密钥生成（执行三次，三个值必须不同）：

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

编辑 `.env`，为 `JWT_SECRET`、`SETUP_TOKEN`、`LAUNCHER_TOKEN` 填入三个互不相同的 64 位十六进制随机值。

然后开两个终端：后端 `npm run dev:server`（`http://127.0.0.1:3000`），前端 `npm run dev:web`（`http://127.0.0.1:5173`）。Vite 已代理 `/api` 与 `/ws`。

## 首次初始化

用户表为空时发送 `POST /api/auth/setup`，header 为 `X-Setup-Token`。密码至少 **12** 位。创建成功后从配置中移除 `SETUP_TOKEN` 并重启面板。之后用普通登录。

PanelManager / `mmdctl` 首次会写入 `config/panel.env` 并自动生成密钥；创建管理员后控制器会去掉 `SETUP_TOKEN`。

## 五分钟开服

1. 侧栏 **一键部署** → Paper，勾选自动接受 EULA。
2. 部署完成后 **启动**。
3. 控制台出现 `Done`。
4. 游戏添加服务器 `127.0.0.1:25565`（版本与部署的游戏版本一致）。

## 故障排查

密钥格式、setup **401**、Java 不可用、部署超时、端口占用：见 [docs/getting-started.md](../getting-started.md) 的故障排查表。

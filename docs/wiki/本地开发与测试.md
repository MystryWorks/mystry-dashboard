# 本地开发与测试

给改面板的人。扩展建议见 [docs/development.md](../development.md)。

## 工作区

npm workspaces：`apps/*` + `packages/*`。需要 Node.js **≥ 22**。

构建顺序必须是 **shared → server → web**。修改 `packages/shared` 后先重建 shared。

## 脚本

| 根脚本 | 作用 |
|--------|------|
| `dev:server` | 后端热重载，`127.0.0.1:3000` |
| `dev:web` | Vite，`127.0.0.1:5173`，代理 `/api` 与 `/ws` |
| `build` | shared → server → web |
| `typecheck` | 三包类型检查 |
| `verify` | 完整门禁 |
| `knowledge:check` | 项目知识库一致性 |
| `audit:production` | 生产依赖审计，拒绝 high / critical |

`verify` 依次执行：`knowledge:check` → `knowledge:test` → `portable:test` → `windows:test` → `linux:test` → 构建 `@mmd/shared` → `typecheck` → `test:security` → `test:regression` → `build` → `test:static`。

调用方式为根目录 `npm run` 加上上表脚本名。

## 测试栈

仓库测试是 `node:test` + `tsx`。没有 Playwright / Cypress 仓库 e2e 套件。

用户可见文案与注释用中文。不要提交 `.env`、`data/`、密钥或 `config/panel.env`。

## 手工 QA 点击路径

1. `GET /api/health` 返回 ok
2. setup + 登录
3. 部署 Paper → 启动 → 控制台 `Done`
4. 游戏连接 `127.0.0.1:25565`
5. ZIP 导入或 `DATA_DIR/imports` 交接
6. 文件页浏览 / 上传 / 编辑
7. 配置页改端口并重启生效
8. 强制停止确认弹窗
9. 运行中实例不能删除
10. 窄屏抽屉、主题、任务铃铛
